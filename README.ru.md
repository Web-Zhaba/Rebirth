Rebirth превращает реальную Землю в градостроительную симуляцию.

Выберите любую точку планеты. Игра проецирует её в **локальный метрический мир** и даёт вам несколько семей, примитивную инфраструктуру и одну задачу:

**сделать так, чтобы это место выжило.**

Дороги требуют труда. Дома — материалов. Людям нужны рабочие места, до которых они действительно могут добраться. Поля подчиняются сезонам. Зиме всё равно, готов ли ваш амбар.

А под новым поселением лежит другой город.

Тот, который существовал здесь раньше.

> Самый важный кадр Rebirth — тот, где деревня, построенная игроком, и город, когда-то существовавший на этом месте, занимают одни и те же координаты.

## Земля помнит

В начале старая цивилизация невидима.

Лес вернул себе землю. Современные здания исчезли. Дороги растворились.

Но данные остались.

Постройте раскоп и поселение начнёт вытаскивать наружу следы мира под собой: фундаменты, улицы, названия мест и исторически значимые объекты.

Находка — не коллекционная карточка.

Восстановите старое здание как памятник — и оно станет частью памяти поселения. Верните его в эксплуатацию — и прошлое снова станет инфраструктурой. Наследие подпитывает исследования, а исследования толкают примитивное поселение к следующей эпохе.

**Прогресс рождается в том числе из понимания того, что уже было здесь.**

## Город — это граф

Rebirth сознательно отказывается от нескольких привычных упрощений city builder.

Рабочий не телепортируется в мастерскую потому, что она попала в радиус.

Служба не обслуживает дом только потому, что между ними мало метров по прямой.

У поселения есть дорожный граф. Готовые дороги формируют проходимые связи. Жители и службы используют эту сеть, чтобы понять, можно ли вообще добраться до нужного места.

Поэтому форма города имеет значение.

Плохо связанный город не просто выглядит плохо.

Он действительно плохо связан.

## Время продолжает идти

Симуляция работает отдельно от UI в Web Worker.

Закрытие вкладки не превращает город в timestamp плюс пару умножителей ресурсов. Rebirth сохраняет состояние симуляции в IndexedDB и умеет догонять время, когда игрок возвращается.

Во время catch-up игра считает, что произошло:

**рождения · смерти · приезды · отъезды · стройка · производство · исследования · события**

А затем показывает сводку пропущенного времени.

## Под картой

Самое интересное в Rebirth — не тот факт, что здесь используются библиотека карт и 3D-движок.

Интересна граница между картой планетарного масштаба и локальной симуляцией.

```text
                         REAL EARTH

                  OpenStreetMap / OpenFreeMap
                             │
                        Terrarium DEM
                             │
                             ▼
                       MapLibre GL JS
                  planet / camera / terrain
                             │
                  local metric projection
                             │
              ┌──────────────┴──────────────┐
              │                             │
              ▼                             ▼
         Three.js layers              Web Worker
      rendered settlement             simulation
              │                             │
      buildings / forest         roads / households
      water / fields             economy / farming
      ruins / weather            weather / research
              │                             │
              └──────────────┬──────────────┘
                             │
                          Preact UI
                             │
                          IndexedDB
```

### Правила принадлежат симуляции

Игровое состояние живёт вне дерева компонентов.

Worker владеет жителями, семьями, дорогами, производством, земледелием, погодой, исследованиями, раскопками, событиями и сохранением.

Main thread получает snapshot'ы и точечные ответы на запросы.

Так UI остаётся представлением симуляции и не превращается постепенно в саму симуляцию.

### Гибридный рендер — осознанное решение

**MapLibre GL JS** решает планетарную географию, векторную карту и поведение камеры.

**Three.js** отвечает за специфические игровые 3D-слои: здания, растительность, воду, поля, жителей, руины и эффекты.

Rebirth не пытается превратить картографический движок в полноценный игровой — и не переписывает глобус с нуля только ради того, чтобы нарисовать деревню.

### Баланс исполняется как код

```bash
npm run pace
```

запускает headless-поселение через настоящий simulation handler.

Harness фиксирует первый дом, первую технологию, первую жатву, переход во II эпоху и рост населения.

Смысл не только в test coverage.

Баланс получает кое-что лучше ощущений:

**цифры.**

## Запуск из исходников

Нужны **Node.js 18+** и npm.

```bash
git clone https://github.com/Web-Zhaba/rebirth.git
cd rebirth
npm install
npm run dev
```

### Скрипты

```bash
npm run dev       # development server
npm run build     # typecheck + production build
npm run preview   # preview production build
npm test          # test suite
npm run pace      # headless pacing simulation
```

## Управление

| Клавиши | Действие |
|---|---|
| `Space` / `P` | Пауза / продолжить |
| `1` `2` `3` | Скорость 1× / 2× / 4× |
| `H` / `Home` | Вернуться к поселению |
| `N` | Исследования |
| `F1` – `F5` | Категории инструментов |
| `Q` – `Y` | Выбрать инструмент |
| `B` | Снос |
| `Esc` / ПКМ | Отменить / закрыть |
| `Enter` | Безопасный выбор события |
| `?` | Справка по горячим клавишам |
